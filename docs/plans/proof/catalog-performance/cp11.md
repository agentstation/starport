# CP11 — Author pages

Date: 2026-08-22. Branch: `codex/cp11-authors`.

## What shipped

- `console/src/lib/api.ts`: `CatalogAuthor` type plus `listAuthors()`
  and `getAuthor(id)` clients for the gateway's `/api/v1/authors`
  endpoints. The list endpoint leaves `models` empty; only the detail
  endpoint populates it.
- `console/src/routes/authors.tsx`: authors list with logos
  (`EntityLogo kind="authors"`), descriptions, external links, and
  per-author model counts. Counts derive from the models list through
  `authorIdsOf`, so the list agrees with the models-page author facet.
  Search covers id, name, and description. Cards sort by model count,
  then name.
- `console/src/routes/authors_.$authorId.tsx`: author detail with the
  logo, bio, headquarters, and external links, plus the author's model
  catalog joined against the routable models list. Each row links to
  `/models/:modelId` and shows context length and live availability
  (`offeringAvailability` counts offerings on healthy or half-open
  circuits). Ids the routable list lacks render muted as
  `not in this snapshot`. A `Browse in the models list` cross-link
  opens `/models?author=<id>`. An unknown author id renders the 404
  contract copy: `This author is not in the current catalog snapshot.`
- Cross-links: the model detail page's author names now link to
  `/authors/:authorId` instead of a models-list search, and the shell
  nav gains an `Authors` entry between Models and Providers.
- `internal/console/spa.go`: `/authors` and `/authors/*` serve the SPA
  shell; `spa_test.go` covers both.
- `scripts/verify-catalog-performance.sh`: CPV09 accepts the un-nested
  `authors_.$authorId.tsx` spelling.

## Contract tests

- `AuthorCard.test.tsx` — model counts from declared authors with the
  id-prefix fallback; external links flatten only populated fields;
  search over id/name/description; count-then-name sort; label prefers
  the display name.
- `spa_test.go` — `/authors` and `/authors/openai` serve the SPA index.
- Fail-before: `/authors` 404s in the SPA — `spaPagePaths` had no
  authors entries and no author routes existed.
