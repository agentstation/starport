# CP12 — Command palette

Date: 2026-08-22. Branch: `codex/cp12-palette`.

## What shipped

- `console/src/components/palette/paletteIndex.ts`: the pure index
  seam. `searchPalette` filters five kinds (pages, actions, models,
  providers, authors) with the models-list fuzzy matcher
  (`fuzzyIncludes`, so `gptoss120` finds `openai/gpt-oss-120b`), ranks
  within each kind (label prefix → label substring → substring
  anywhere → subsequence-only), and caps each kind at six so one kind
  never floods the list. An empty query browses pages and actions
  only.
- `console/src/components/palette/CommandPalette.tsx`: the global ⌘K /
  Ctrl+K surface. It stays mounted in the shell; opening it starts the
  models, provider-catalog, and authors queries, which share cache
  keys with the pages. Rows show entity logos for providers and
  authors and a kind label; Enter navigates to the entity detail page,
  runs an action (toggle theme, new chat), or opens a page. Keyboard
  traversal: arrows, Home/End, Enter, Escape; `aria-activedescendant`
  tracks the active option. The shell's Search button and the
  shortcut share one entry point (`openCommandPalette` window event).
- `console/src/components/shell/Shell.tsx`: a `Search ⌘K` button above
  the nav opens the palette; the palette mounts once in the shell.
- The chat model-picker's keys are listbox-local, so the global ⌘K
  shortcut coexists without scoping conflicts.

## Contract tests (named acceptance cases)

- "finds one of each entity kind by fuzzy query" — `gptoss120` →
  model, `groq` → provider, `anthro` → author, `models` → page,
  `dark` → action (keyword match).
- "substring matches rank before subsequence-only matches" — `meta`
  puts `meta/llama-3.1-8b-instruct` above `google/aqa` (whose long
  name merely contains m-e-t-a in order).
- "an empty query shows pages and actions, not entities"; "each kind
  is capped so one kind cannot flood the list".
- "⌘K opens the palette and keyboard-only traversal navigates" —
  jsdom: ⌘K opens, typing `gptoss120` lists the model, Enter calls
  navigate with `/models/$modelId` and closes; Escape closes without
  navigating.
- Fail-before: CPV10 red — no palette component existed.
