# CM10 proof: chat shell and composer

Date: 2026-08-21. Branch: `codex/cm-10-chat` on main @ 1365e6b.

## What landed

- `console/src/lib/chatStore.ts`: the persistence seam for chat. It
  carries the legacy contract unchanged so existing history survives
  the cutover: `starport.chats` (with `starport_chats` migration),
  `starport.favModels`, `starport.lastModel`, `starport.chatSidebar`,
  a 100-conversation cap, 300 ms debounced saves, and the legacy
  message shape (`reasoning`, `stats`, `error`, `stopped`). New
  additions stay inside the same shape: `params.effort` for
  reasoning effort and `statsFromUsage` to derive ttft/tps records
  from stream usage.
- `console/src/lib/api.ts`: `streamChat` (SSE over
  `/api/v1/chat/completions` with `stream_options.include_usage`,
  delta + reasoning callbacks, cache headers into `ChatStreamMeta`)
  and `completeChat` for title generation.
- `console/src/components/chat/ModelPicker.tsx`: the composer model
  popover — search, Pinned, Presets (`@preset/name`), then provider
  groups from the live `/models` response. Rows show capability
  badges (vision/reasoning/tools), context and per-M prices from
  catalog facts, mono model IDs, and a star pin toggle. Full
  keyboard navigation. No model data lives in the frontend.
- `console/src/components/chat/Composer.tsx`: bottom input bar in
  the ChatGPT/Claude style — auto-growing textarea, Enter to send,
  model trigger with the picker opening upward (⌘K), a reasoning
  effort menu that appears only for models whose
  `supported_parameters` include reasoning, a params popover
  (system, temperature, max tokens, provider order/only/ignore,
  sort), a presets plus-menu, and a send button that flips to Stop
  while streaming.
- `console/src/components/chat/ThreadList.tsx`: thread sidebar with
  search, legacy recency grouping (Pinned/Today/Yesterday/7d/30d/
  Older), inline rename, pin toggle, and a destructive delete modal.
- `console/src/routes/chat.tsx`: the chat page. Full-height layout
  (Shell cedes its container on `/chat`), empty state with starter
  prompts, per-thread model + params persistence, streaming with
  abort (Escape or Stop keeps partial output and marks "Stopped."),
  fire-and-forget title generation, and `?model=` seeding from the
  Models page. Error turns render once, and a 401 shows the
  gateway's own message ("Provider credentials are not
  configured.") instead of always blaming the console key.
- CM11 owns rendering depth: Streamdown markdown, reasoning
  disclosure, metadata line, hover actions, scroll pill. CM10
  stores reasoning and stats but renders plain text.
