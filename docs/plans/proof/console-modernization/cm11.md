# CM11 proof: streaming and messages

Date: 2026-08-21. Branch: `codex/cm-11-messages` on main @ 3fd6a38.

## What landed

- Streamdown 2.5.0 with the `@streamdown/code`, `@streamdown/math`,
  and `@streamdown/mermaid` plugins (Shiki, KaTeX, Mermaid all
  bundled — no CDN, the air-gap invariant holds). `katex` pinned to
  0.16.47 to match the plugin's peer range. `app.css` imports
  `streamdown/styles.css` + KaTeX CSS and `@source`-scans the four
  dists; a `@custom-variant dark` line binds Streamdown's `dark:`
  utilities to our class-based dark-default theme. `tokens.css`
  gains a shadcn-vocabulary bridge (`--color-background` →
  `--bg-canvas` and friends) so Streamdown components resolve to
  role tokens, plus `--radius-xl` (a latent CM10 gap: `rounded-xl`
  previously generated no CSS).
- `console/src/components/chat/Messages.tsx`: the message rendering
  seam. `Markdown` wraps Streamdown (`mode` streaming/static,
  controls: copy on code/table/mermaid, downloads off, mermaid
  pan-zoom + fullscreen). `ReasoningFold` is a collapsible
  disclosure that follows the stream ("Thinking…" → "Thought for
  N.Ns") unless the user toggles it. `MetadataLine` renders the
  mono stats row: ttft, total, tok/s, ↓prompt ↑completion tokens,
  reasoning tokens, cost from catalog pricing, cache hit/miss (+
  age, green on hit), "stopped" and "unenforced" warnings.
  `AssistantMessage` adds a live ~tok/s badge while streaming and
  hover actions (copy, retry / retry-with-model menu).
  `UserMessage` gets hover copy + edit-in-place (textarea, Enter
  submits, Escape cancels).
- `console/src/routes/chat.tsx` rewired: scroll lock with an
  un-pin on scroll-up and a "↓ Latest" pill; `send`/`sendTo` split
  so retry and edit can resend into a truncated conversation;
  reasoning timing (`reasoningMs`) measured at the content
  boundary; the abort path now also preserves reasoning-only
  partials (CM10 dropped them).
