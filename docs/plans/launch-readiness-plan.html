A merged pull request closes each remaining gap, or an owner action with an exact command and a verifier records it.

Architecture

The release chain exists today. The plan repairs its inputs: the environment secrets, the signing material, the public copy, and the entry points.

Scope

Owns: the launch-readiness review of agentstation/starport, the in-repository fixes it found, the owner action list with exact commands, and the verifiers that prove each item. It also owns the cliproxyapi assessment for subscription-plan credentials.

Does not own: the Starmap release and catalog schedule, which the Starmap repository owns. The release tag itself and the paid first-use recording belong to the owner. Cloudflare account configuration belongs to the owner. A successor plan designs and implements subscription credentials (D5).

Non-goals: a version 2 module path, new product features, and a redesign of the site. The plan makes no change to a test assertion to hide a failure. No agent acts on repository settings, secrets, tags, or Cloudflare.

Invariants

  1. No secret value, API token, or full gateway key appears in this plan, its proof root, a commit, or a pull request.
  2. Only the owner creates release tags, edits repository settings, adds secrets, or changes Cloudflare, and agents record the exact command and stop.
  3. Public copy at launch describes released behavior, so the release that carries the new CLI precedes the announcement.
  4. No one weakens a test, an assertion, or a verifier to pass. Each failing check gets a fix at its owning package or a recorded blocker.
  5. Every merge lands at the exact reviewed head through the protected branch with the four required checks green.
