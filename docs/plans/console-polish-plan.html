Console polish plan

Status: active · Owner: this plan · Created: 2026-09-01 · Baseline: main @ 6db57d8 · Proof root: docs/proof/console-polish/ · Next action: finish CPL-C2 on codex/cpl-c2, then start CPL-C3

Outcome

Every console surface is built from one set of accessible primitives, one query layer, one table, one chart wrapper, and one formatting vocabulary. Every enterprise feature that the gateway ships has a console read surface, and every cascading write asks first. The console reads the same on a phone and on a desk. Starport v1.2.0 ships with these changes and a verifier that stays green at 48 conditions in CI.

Progress

Progress appears here when the page loads. The status ledger below is the source of truth.

Architecture

Dashed boxes are the parts this plan replaces. Solid boxes in the after view are the parts it creates. Route files keep their names.

Scope

Owns: the console at console/: its query layer, router setup, primitives, tables, charts, formatting, page copy, and small-screen layout.

Owns, gateway side: the read surfaces the console needs. Honest system info. A webhook summary. Budget usage on team and account reads. Typed guardrail fields on activity records and the until audit filter. The v1.2.0 release.

Does not own: new gateway features. A server aggregate endpoint for usage series stays with a future usage plan. Bulk row actions stay with a future keys and files plan. The agentstation/skills mirror stays with the skills repository.

Non-goals: a visual redesign. DESIGN.md stays the design system and this plan applies it. A component library other than shadcn on Base UI. A chart library other than Recharts. A form library. Organization tiers above accounts.

Invariants

I1 Design system. The seven laws in DESIGN.md hold on every screen. The laws are one accent, mono for data, borders as elevation, role-mapped neutrals, a weight 600 ceiling, dense tables, and color as state. Components from shadcn take their colors from tokens.css. No default shadcn palette reaches the bundle.

I2 Self-hosted. The built console stays self-hosted. No runtime request leaves the gateway origin for a script, style, or font.

I3 Credentials. The console keeps the two credential paths that exist today, the launch-ticket session and the stored gateway API key. This plan adds no third path and shows no secret that the console does not show today.

I4 Overlays. Every modal overlay traps focus, restores focus on close, closes one layer on Escape, locks page scroll, and names itself with aria-labelledby. Every non-modal overlay closes on Escape, returns focus to its trigger, and carries an accessible name.

I5 Motion. Every animation honors prefers-reduced-motion.

I6 API. Gateway API changes are additive. Existing JSON fields keep their names and types. The health endpoints keep their version contract.

I7 Checks. pnpm -C console check is green at every merge. The console test count never decreases.

I8 Bundle. The entry chunk of the built console stays at or under 130 kB gzip against the baseline that CPL-A0 records.

I9 Gates. Existing verifier gates keep their terminal counts. AON 26, CSG 16, MMD 26, FIL 22, AMJ 18, PLG 20, and RNK 22 hold. CSH 23, ORP 17, CDP 19, ENR 33, CM 21, and CP 20 hold.

Decisions

Primitives. shadcn 4.19 on Base UI (@base-ui/react 1.7). The package @base-ui-components/react is stale at a release candidate and is not used.

Toasts. Toasts use sonner. One line, bottom right, four seconds, a semantic left rule, role="status".

Palette. The command palette moves to cmdk. Keyboard behavior stays as it is today.

Select. The native Select stays. The DESIGN.md styled select is a styling pass, not a primitive swap.

Chart interval. The interval follows the range. One hour uses five minutes. One day uses one hour. Seven days use six hours. Thirty days use one day.

Order. Task order inside a phase is the listed order. Phases B and C land before D, E, F, and G, because the later phases build on the primitives and the query layer.

Delivery. Every task ships as one pull request on a codex/ branch, with the pre-PR autoreview gate. It merges by squash after CI is green.
