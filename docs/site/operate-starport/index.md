This area is for operators who keep a Starport gateway or fleet in service. It starts after the first installation and the storage selection.

The topics cover who can open the console and how. They cover how a fleet shares its stores and how the catalog changes over time. They also cover the signals that a monitoring system reads, and how to stop and upgrade a gateway safely.

Each procedure has a verification step that you can run from a shell. Most checks need a gateway key with the `admin` scope. A local admin token opens the console only from the gateway host or through a launch link.

Starport requires a gateway API key by default. Keep that default on each address that the network can reach.
